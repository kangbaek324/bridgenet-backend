## 💫 Features

### Auth
- 회원가입
- 로그인

### Bridge
- 코인 교환
- 교환 가능 체인 리스트 
- 교환 기록 조회 
- 교환 옵션 설정 (수동, 자동 처리)
- 스마트컨트랙트 코인 충전 
- 스마트컨트랙트 잔액 조회
- 교환 통계


## 📂 Architecture

- System
- DataBase

## 🛠️ Stack
### Backend
- Languages: Java
- Frameworks: Spring Boot
- Database: Mysql 
- Blockchain: Web3j

### SmartContract
- Languages: Solidity
- Frameworks: Hardhat
- Library: OpenZeppelin
